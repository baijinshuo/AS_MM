## 1. 目标

以 Avellaneda & Stoikov (2008) 高频做市模型为基准，构建一套面向境内（中金所）国债期货市场的做市量化策略系统，以最大化盈利为目标。交付物包括：AS 模型核心、参数校准、事件驱动回测引擎、风控系统、市场仿真器、绩效分析与参数寻优工具。

## 2. 数学模型

### 2.1 原始 AS 模型

- 中间价 `S_t` 服从布朗运动，波动率 `σ`
- 做市商库存 `q`（有符号，单位：手），现金 `X`，风险厌恶系数 `γ`，到期 `T`
- 限价单成交强度随距离衰减：`λ(δ) = A·exp(-k·δ)`（δ 为距中间价的距离）
- 目标：最大化期末财富的 CARA 效用 `E[-exp(-γ(X_T + q_T·S_T))]`

### 2.2 求解结果（近似解，工程实现采用）

- **保留价格**：`r = S - q·γ·σ²·(T-t)`（库存越多，报价中枢越向下偏移，鼓励卖出）
- **最优总价差**：`δa + δb = γ·σ²·(T-t) + (2/γ)·ln(1 + γ/k)`
- **对称报价**：`bid = r - δ/2`，`ask = r + δ/2`

### 2.3 单位换算（国债期货合约乘数）

AS 公式中资产价格以"元/手"计。国债期货 1 手的现金价值 = `P × M`（P 为净价报价，M 为合约乘数）。定义**有效风险厌恶系数**（价格单位空间）：

`Γ = γ·M`（单位：1/(价格·手)）

则全部公式在价格单位下成立：
- `r = P - q·Γ·σ_P²·τ`，其中 τ = T-t（秒），σ_P 为每√秒价格波动率
- `δ = Γ·σ_P²·τ + (2/Γ)·ln(1 + Γ/k)`，k 以 1/价格单位 计

Γ 的选择由库存风险预算反解：`Γ = m·tick / (σ_P²·τ_typ·q_max)`，即库存打满时偏移 m 个 tick。

## 4. 市场仿真器设计

### 4.1 价格过程

- 基础扩散：`dP = σ_t·√dt·Z`，Z~N(0,1)
- 日内波动率 U 型：`σ_t = σ_day·φ(t)`，φ 在开盘/收盘附近放大（E[φ²]=1 归一化）
- **订单流冲击**（产生逆向选择的来源）：`dP += η·(n_b - n_s)`，n_b/n_s 为本步市价买/卖单净手数——我方卖单成交于买单流，而买单流推高中间价，自然产生对做市商不利的 markout

### 4.2 订单簿

- 市场最优价由中间价 + 价差生成：`best_bid = tick·floor((P-h)/tick)`，`best_ask = best_bid + m·tick`，m~Geometric(p) 随 Poisson 时钟重抽
- 触价排队量 Q~指数分布均值，市价单按 FIFO 消耗排队量，排队量按泊松过程回补
- 中间价移动导致簿档位迁移时，排队量重置

### 4.3 成交判定（我方限价单）

1. **挂单价优于市场最优价**（价差内部改善）：成为簿上最优，下一个对向市价单直接成交
2. **挂单在触价档**：排在现有 Q 手之后，Q 被耗尽且剩余量≥1 时成交
3. **挂单深于触价**：仅当中间价下移使新触价档==我方价格时，我方视为先到（排队量=0），奖励深度被动报价
4. **价格穿越**：簿档位变动导致我方报价被穿越时立即成交

我方报价与市场簿合并：有效 best_bid = max(市场bid, 我方bid)。

## 5. 策略逻辑（每 0.5s 步）

1. EWMA 更新 σ̂（5s 采样中间价收益）
2. 计算 Γ·σ̂²·τ（τ=距收盘秒数）→ 保留价 r 与最优半价差
3. 报价取整到 tick 网格，保证 bid/ask 间 ≥1 tick
4. 风控过滤：|q|≥q_max → 撤掉加仓方向报价；亏损触限 → 停止报价并被动平仓；报价裁剪至涨跌停带内
5. 尾盘（收盘前 15 分钟）进入清仓模式：库存方向单边贴触价报价，收盘前 30s 仍不平则按穿价强平（支付半价差+滑点）

## 6. 回测引擎与记账

- 事件循环：逐日逐 0.5s 步进，先市价流→成交判定→我方报价更新
- 持仓记账：`equity = realized + unrealized - fees`，每步校验恒等
- 费用：每笔成交 `fee_rate × P × M`；保证金占用 = `|q|·P·M·margin_rate`（仅用于资金效率报告）
- 随机数预生成（numpy 向量化）后进入纯 Python 状态机循环，10 天×32,400 步 ≈ 数秒量级

## 7. 绩效分析与参数寻优

- PnL 分解：价差捕获（回合交易）、库存损益、费用
- 指标：总 PnL、日 PnL 序列 Sharpe（√252 年化）、最大回撤、成交数、平均捕获价差/tick、markout（1/5/30/120s）、平均库存、保证金占用效率
- 基准对比：① 完整 AS（偏移+价差）② 无库存偏移（固定价差）③ 朴素固定 2tick 报价——验证 AS 库存管理价值
- 参数扫描：Γ × k 网格 → PnL/Sharpe 热力图，服务于"最大盈利"目标下 γ 的选取（γ→0 趋近利润最大化但库存风险失控，扫描量化该权衡）

## 8. 测试

- 模型数学：保留价关于 q 单调线性、对称性；价差关于 Γ/σ 单调、τ→0 极限；报价取整不交叉
- 记账：回合交易 PnL 手工核算一致（含费用）
- 回测不变量：每步 equity 恒等式、成交仅在交易时段、|q| ≤ q_max、报价在 tick 网格
- 校准：由已知 A,k 生成的成交数据反估，误差 <15%
- 仿真：路径实际波动率 ≈ 配置值（统计容差）

## 9. 已知简化（诚实披露）

- 仿真数据非真实行情；真实数据可通过实现 `market_sim` 同接口的加载器接入
- 报价撤换即时生效、无延迟与废单；中金所无撤单费，但实际存在系统延迟
- 假定保证金充足、无强平；未建模跨期主力移仓
- AS 近似解而非有限时域精确解（工程标准做法）
